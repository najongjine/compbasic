* 홈 -> 레이아웃에서 레이아웃 골라보기

* 삽입-> 기호   에서 기호 넣어보기

* 슬라이드 삽입 복제 삭제 이동

* 단락 다루기
  내용 드래그 -> 홈-> 상단 중앙에서 목록수준 늘림, 줄임
  OR
  내용 드래그 -> 탭 | shift + 탭

* 글머리 기호 넣기 | 바꾸기
  홈 -> 상단중앙

  아이콘을 기호로 넣기는
  작은 화살표 -> 글머리 기호 및 번호 매기기 -> 그림 -> 아이콘

* 글꼴, 글자크기, 색상 바꾸기
    홈화면에 다 있음

* 사진 넣기
    삽입 -> 그림

  그림 클릭후
  그림 서식 -> 원하는 테두리 그림 적용하기

* 배경서식
    슬라이드 본문에서 우클릭 -> 배경 서식
    단색 채우기
    그라데이션 채우기
    그림 또는 질감 채우기
    패턴 채우기

* 워드 아트
    삽입 -> 중간 우측쪽에 워드 아트
    그후 텍스트 드래그후 도형서식으로 가면 더 꾸밀수 있음

* 도형, 도형에 텍스트 넣기
    삽입-> 도형
    도형 우클릭후 앞으로 가져오기
    도형 선택후 만 오른쪽에 있는 도형 서식에서 꾸밀수 있음
    도형 클릭수 그냥 글 입력하면 됨
    ctrl + shift + 드래그로 복사할수 있음
    
* 스마트 아트
    삽입 -> 스마트 아트

* 표
    삽입 -> 표
    표 셀을 마우스 우클릭으로 병합, 분할 할수있음
    표 선택후 레이아웃에서 크기 정렬 할수있음
    표 셀안에 그림 넣을때는 테이블 디자인 -> 음영 -> 그림
