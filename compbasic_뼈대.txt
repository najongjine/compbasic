컴퓨터 기초 + AI 활용 2주 커리큘럼 뼈대

대상
- 타자 입력은 가능함
- 이메일이 무엇인지는 어느 정도 알고 있음
- 네이버 정도는 사용해봤음
- Google, GPT, Suno, 엑셀, 한글 문서 작업은 익숙하지 않음

전체 수업 조건
- 기간: 총 2주
- 횟수: 10일 기준
- 시간: 하루 3시간
- 주요 내용: GPT, Suno, GPT 이미지 편집/생성, 한글, 엑셀

전체 방향
- 네이버/검색 탐구보다 "실제로 남는 결과물" 중심으로 진행한다.
- 한글과 엑셀은 자격증 시험식 기능 암기가 아니라 회사에서 자주 쓰는 문서와 자료 정리 위주로 진행한다.
- GPT는 글쓰기, 이미지 요청문, 문서 초안, 표 구조 설계를 도와주는 보조 선생님처럼 사용한다.
- 매일 결과물을 저장하고, 다음 수업에서 다시 열어보게 한다.

전체 목표
- GPT에게 질문하고 원하는 답변을 얻을 수 있다.
- Suno로 간단한 노래를 만들어볼 수 있다.
- 무료 계정 GPT의 가능한 범위 안에서 이미지 편집/생성 요청을 해볼 수 있다.
- GPT와 이미지 생성 기능으로 짧은 동화책을 만들어볼 수 있다.
- 한글로 회사에서 쓰는 보고서, 회의록, 안내문 양식을 만들 수 있다.
- 엑셀로 회사 자료를 정리하고, 자주 쓰는 함수로 합계/평균/개수/조건별 계산을 할 수 있다.

하루 수업 기본 흐름
- 1교시 30분: 전날 만든 결과물 다시 열기, 복습, 질문 확인
- 2교시 60분: 오늘 필요한 기능 배우기
- 3교시 60분: 선생님과 같이 결과물 만들기
- 4교시 30분: 내 주제로 바꿔보기, 저장하기, 발표하듯 확인하기


1일차: GPT 기초

오늘의 성취 주제
- "내 전용 컴퓨터 선생님" 만들기

만들거나 해볼 것
- GPT에게 질문하고 답변 받아보기
- 어려운 설명을 쉽게 바꿔달라고 하기
- 답변을 복사해서 저장하기

수업 목표
- GPT가 무엇인지 이해한다.
- 질문을 입력하고 답변을 받을 수 있다.
- 답변이 마음에 들지 않을 때 다시 요청할 수 있다.

수업 내용
- GPT 접속하기
- 질문 입력하기
- 답변 읽기
- "쉽게 설명해줘", "짧게 정리해줘", "예시 들어줘" 요청하기
- 답변 복사해서 메모장이나 한글에 붙여넣기

실습 예시
- "컴퓨터 초보자가 배워야 할 것 5가지를 알려줘"
- "스마트폰 사진을 컴퓨터로 옮기는 방법을 쉽게 설명해줘"
- "가족 모임 안내 문자를 만들어줘"

결과물
- GPT 답변을 복사해 저장한 문서 1개

메모
- 1일차에는 GPT로 물어보고 답변 얻는 것을 진행했음


2일차: Suno 사용하기

오늘의 성취 주제
- "내 인생 첫 AI 노래" 만들기

만들거나 해볼 것
- 내 이름, 가족, 가게, 취미, 생일 중 하나를 주제로 노래 만들기
- 같은 가사로 분위기를 바꿔보기
- 마음에 드는 노래 고르기

수업 목표
- Suno가 무엇인지 이해한다.
- 노래 주제, 분위기, 장르를 입력할 수 있다.
- GPT로 가사를 만든 뒤 Suno에 넣어 노래를 만들 수 있다.

수업 내용
- Suno 접속하기
- 노래 만들기 화면 살펴보기
- 노래 주제 정하기
- 장르와 분위기 정하기: 트로트풍, 발라드풍, 신나는 댄스풍, 잔잔한 카페풍
- GPT로 가사 만들기
- Suno에 입력해서 노래 생성하기
- 마음에 드는 결과 고르기

실습 예시
- 내 이름으로 응원가 만들기
- 가족 모임 노래 만들기
- 생일 축하 노래 만들기
- 가게 홍보송 만들기
- 취미 생활 주제가 만들기

결과물
- Suno로 만든 짧은 노래 1곡
- GPT로 만든 가사 문서 1개


3일차: 무료계정 GPT로 이미지 편집하기

오늘의 성취 주제
- "사진 한 장을 카드뉴스처럼 바꿔보기"

만들거나 해볼 것
- 사진이나 이미지를 GPT에 올려 설명받기
- 이미지에서 바꾸고 싶은 점을 말로 요청하기
- 문구가 들어간 홍보 이미지나 축하 이미지 아이디어 만들기
- 무료 계정 한도 안에서 이미지 생성 또는 편집을 시도해보기

수업 목표
- GPT에 이미지를 올리고 질문할 수 있다.
- 이미지에 대해 "무엇을 바꿀지" 말로 설명할 수 있다.
- 원하는 분위기, 색감, 문구를 요청하는 법을 익힌다.
- 이미지 기능은 계정 상태와 일일 한도에 따라 달라질 수 있음을 이해한다.

수업 내용
- 이미지 업로드하기
- 이미지 내용 설명 요청하기
- "더 밝게", "글자를 넣어줘", "포스터처럼", "깔끔하게" 같은 요청하기
- 이미지 편집 요청 문장 만들기
- 결과가 마음에 들지 않을 때 수정 요청하기
- 저장 또는 다운로드 위치 확인하기

실습 예시
- 가족 사진을 따뜻한 초대장 분위기로 바꾸기
- 가게 사진을 홍보 이미지 느낌으로 바꾸기
- 음식 사진에 짧은 소개 문구 넣는 아이디어 만들기
- 오래된 안내문 사진을 깔끔한 문서 문장으로 바꾸기
- 손글씨나 종이 안내문 사진을 GPT에게 읽어달라고 하기

결과물
- 이미지 편집 요청문 3개
- GPT로 설명받은 이미지 내용 1개
- 가능하면 편집 또는 생성한 이미지 1장

시간남으면 번역하기, 요약하기


4일차: GPT + 이미지 생성 기능으로 동화책 만들기

오늘의 성취 주제
- "4쪽짜리 AI 동화책" 만들기

만들거나 해볼 것
- GPT로 짧은 동화 줄거리 만들기
- 주인공, 장소, 사건을 정하기
- 장면별 그림 요청문 만들기
- 이미지 생성 기능으로 동화 삽화 만들기
- 글과 그림을 모아 동화책 초안 만들기

수업 목표
- GPT로 이야기 구조를 만들 수 있다.
- 같은 주인공이 이어지는 이미지 요청문을 작성할 수 있다.
- 이미지 생성 결과가 마음에 들지 않을 때 수정 요청을 할 수 있다.
- 무료 계정 한도에 따라 이미지 생성 횟수를 조절하는 법을 익힌다.

수업 내용
- 동화 주제 정하기: 용기, 가족, 친구, 여행, 습관
- 등장인물 만들기
- 4쪽 구성 만들기: 시작, 문제, 해결, 마무리
- 각 쪽의 짧은 문장 만들기
- 각 장면 이미지 요청문 만들기
- 이미지 생성 또는 대체 이미지 아이디어 만들기
- 결과물 저장하기

실습 예시
- 길을 잃은 아이가 집을 찾아가는 이야기
- 말하는 연필과 초보 컴퓨터 사용자의 모험
- 작은 가게를 살리는 홍보 노래 이야기
- 할머니와 AI가 같이 만든 생일잔치 이야기

결과물
- 4쪽짜리 동화 원고
- 장면별 이미지 요청문 4개
- 가능하면 동화 삽화 이미지 2-4장


5일차: 한글 회사 문서 기초

오늘의 성취 주제
- "깔끔한 업무 보고서 양식" 만들기

만들거나 해볼 것
- 회사 보고서 기본 틀 만들기
- 제목, 작성자, 날짜, 부서, 요약, 본문, 결론 영역 만들기
- 글자 크기와 정렬을 맞춰 읽기 좋게 만들기

수업 목표
- 한글에서 회사 문서의 기본 모양을 만들 수 있다.
- 제목/본문/소제목을 구분해 문서를 정리할 수 있다.
- 문서를 저장하고 다시 열어 수정할 수 있다.

수업 내용
- 새 문서 만들기
- 문서 제목과 기본 정보 입력하기
- 글자 크기, 굵게, 정렬, 줄 간격 조정하기
- 번호 목록과 글머리표 사용하기
- 문단 간격 정리하기
- 파일 이름을 업무용으로 저장하기

실습 예시
- 주간 업무 보고서
- 교육 참석 보고서
- 매장 운영 보고서
- 고객 응대 개선 보고서

결과물
- 한글 업무 보고서 양식 1개


6일차: 한글 실무 문서 만들기

오늘의 성취 주제
- "회의록 + 안내문까지 한 번에" 만들기

만들거나 해볼 것
- 회의록 양식 만들기
- 표가 들어간 일정/담당자 정리 문서 만들기
- 인쇄 미리보기와 PDF 저장해보기

수업 목표
- 표가 들어간 실무 문서를 만들 수 있다.
- 회의 내용, 결정 사항, 담당자, 기한을 문서로 정리할 수 있다.
- 회사에서 제출 가능한 형태로 문서를 다듬을 수 있다.

수업 내용
- 표 만들기
- 표에 글자 입력하기
- 칸 너비 조절하기
- 표 제목 줄 꾸미기
- 사진 또는 로고 넣기
- 여백 확인하기
- 인쇄 미리보기
- PDF로 저장하기

실습 예시
- 회의록: 안건, 참석자, 결정 사항, 담당자, 기한
- 업무 안내문: 제목, 대상, 일정, 장소, 준비물
- 교육 일정표: 시간, 내용, 담당자, 비고
- 업무 요청서: 요청 내용, 담당자, 마감일

결과물
- 표가 들어간 회의록 또는 업무 안내문 1개


7일차: 엑셀 회사 자료 정리 기초

오늘의 성취 주제
- "엉킨 회사 자료를 보기 좋은 표로 정리하기"

만들거나 해볼 것
- 고객/상품/매출 같은 자료를 표로 입력하기
- 칸 넓이, 제목 줄, 테두리, 색을 정리하기
- 정렬과 필터로 필요한 자료만 보기

수업 목표
- 엑셀의 셀, 행, 열 개념을 이해한다.
- 회사 자료를 표 형태로 정리할 수 있다.
- 정렬과 필터를 사용해 자료를 찾을 수 있다.

수업 내용
- 엑셀 실행하기
- 셀, 행, 열 이해하기
- 표 머리글 만들기
- 글자와 숫자 입력하기
- 칸 넓이 조절하기
- 테두리와 색 넣기
- 정렬하기: 날짜순, 금액순, 이름순
- 필터 사용하기
- 틀 고정 맛보기

실습 예시
- 고객 문의 목록
- 상품 재고 목록
- 매출 내역표
- 직원 교육 참석 명단

결과물
- 정렬/필터가 가능한 회사 자료 표 1개


8일차: 엑셀 자주 쓰는 함수

오늘의 성취 주제
- "합계, 평균, 개수는 엑셀이 하게 만들기"

만들거나 해볼 것
- 매출표 또는 지출표 만들기
- SUM, AVERAGE, COUNT, COUNTA 사용하기
- MAX, MIN으로 가장 큰 값/작은 값 찾기
- 자동 채우기로 계산식 복사하기

수업 목표
- 회사에서 자주 쓰는 기본 함수를 사용할 수 있다.
- 계산식을 복사하고 수정할 수 있다.
- 숫자 자료를 빠르게 요약할 수 있다.

수업 내용
- 숫자 입력하기
- =SUM() 합계
- =AVERAGE() 평균
- =COUNT() 숫자 개수
- =COUNTA() 비어 있지 않은 칸 개수
- =MAX(), =MIN()
- 자동 채우기
- 금액 표시와 쉼표 표시

실습 예시
- 월별 매출 합계 구하기
- 직원별 교육 점수 평균 구하기
- 상품별 재고 수량 합계 구하기
- 지출 내역에서 최고/최저 금액 찾기

결과물
- 기본 함수가 들어간 매출/지출/재고 표 1개


9일차: 엑셀 조건별 정리와 실무 함수

오늘의 성취 주제
- "필요한 것만 골라 계산하는 업무표" 만들기

만들거나 해볼 것
- 조건에 맞는 자료만 세기
- 조건에 맞는 금액만 더하기
- 상태값을 표시하기
- 보기 좋게 마감일/상태표 만들기

수업 목표
- COUNTIF, SUMIF 같은 실무 함수를 사용할 수 있다.
- IF 함수로 상태를 자동 표시할 수 있다.
- 필터와 함수로 회사 자료를 빠르게 확인할 수 있다.

수업 내용
- =COUNTIF() 조건에 맞는 개수 세기
- =SUMIF() 조건에 맞는 금액 더하기
- =IF() 조건에 따라 표시하기
- 필터로 부서별/상태별 보기
- 중복값 확인 맛보기
- 간단한 조건부 서식 맛보기

실습 예시
- 부서별 교육 참석 인원 세기
- 담당자별 매출 합계 구하기
- 재고 부족 상품 표시하기
- 미완료 업무만 필터로 보기
- 마감일 지난 업무에 표시하기

결과물
- 조건별 계산과 상태 표시가 들어간 업무 관리표 1개


10일차: 한글 + 엑셀 실무 종합

오늘의 성취 주제
- "회사에 제출할 수 있는 보고서 세트" 만들기

만들거나 해볼 것
- 엑셀로 자료 정리하기
- 함수로 합계/평균/조건별 계산하기
- 한글로 보고서 작성하기
- 엑셀 표를 보고서에 붙여넣기
- PDF로 저장하기

수업 목표
- 한글과 엑셀을 연결해서 실무 보고서를 만들 수 있다.
- 숫자 자료를 정리하고 문서로 설명할 수 있다.
- 저장, 수정, PDF 제출까지 해볼 수 있다.

수업 내용
- 실습 주제 정하기
- 엑셀 자료 입력하기
- 정렬, 필터, 함수로 자료 정리하기
- GPT로 보고서 문장 초안 만들기
- 한글 보고서 양식에 내용 넣기
- 엑셀 표를 한글에 붙여넣기
- 인쇄 미리보기와 PDF 저장

최종 프로젝트 예시
- 월간 매출 보고서: 매출표 + 합계/평균 + 한글 보고서
- 재고 점검 보고서: 재고표 + 부족 상품 표시 + 한글 보고서
- 교육 참석 결과 보고서: 참석 명단 + 참석률/평균 점수 + 한글 보고서
- 고객 문의 처리 보고서: 문의 목록 + 처리 상태 + 한글 보고서
- 행사 준비 보고서: 예산표 + 담당자표 + 한글 보고서

결과물
- 엑셀 업무 자료 1개
- 한글 보고서 1개
- PDF 제출본 1개
- GPT 활용 기록 1개


수업 운영 팁
- 시작할 때 오늘 만들 결과물을 먼저 보여준다.
- 설명은 짧게 하고, 바로 따라 하게 한다.
- 기능 이름을 외우게 하기보다 "어떤 회사 문서를 만들 때 쓰는지" 중심으로 설명한다.
- 한글은 보고서, 회의록, 안내문처럼 실제 제출 문서 위주로 진행한다.
- 엑셀은 자료 입력, 정렬, 필터, 합계, 평균, 조건별 계산처럼 자주 쓰는 기능 위주로 진행한다.
- 매일 결과물을 하나씩 저장하게 한다.
- 저장 위치와 파일 이름 정하는 연습을 반복한다.
- 무료 계정은 사용 가능 횟수나 기능 제한이 있을 수 있으므로, GPT 이미지 기능이 막히면 요청문 만들기와 이미지 설명 실습으로 전환한다.

추천 진행 순서
GPT 기초 -> Suno 사용 -> 무료계정 GPT 이미지 편집 -> GPT + 이미지 생성 동화책 -> 한글 보고서 양식 -> 한글 회의록/안내문 -> 엑셀 회사 자료 정리 -> 엑셀 기본 함수 -> 엑셀 조건별 함수 -> 한글+엑셀 실무 종합
