1장. 한글 시작과 저장

목표: 새 문서를 만들고, 이름을 붙여 저장하고, 다시 열 수 있다.

목차다음 장

왜 배우나

문서를 잘 만들어도 저장을 못 하면 끝입니다. 회사에서는 파일 이름과 저장 위치가 매우 중요합니다.

오늘부터 “문서1.hwpx”처럼 저장하지 않습니다. 파일 이름만 봐도 내용이 보이게 저장합니다.

따라하기

1

새 문서

작업
한글을 실행하고 빈 문서를 연다.
누를 것
한글 실행 → 새 문서
확인
흰 종이가 보이면 성공
2

저장

작업
빈 문서를 먼저 저장한다.
누를 것
Ctrl + S
파일명
5일차_내이름_연습문서.hwpx
확인
폴더에 파일이 생기면 성공

파일 이름 규칙

나쁜 예좋은 예
문서1.hwpx5일차_홍길동_주간업무보고서.hwpx
새파일.hwpx2026-06-12_교육참석보고서_홍길동.hwpx

연습

  • □ 새 문서를 만든다.
  • □ 내 이름이 들어간 파일명으로 저장한다.
  • □ 한글을 닫았다가 다시 파일을 연다.
