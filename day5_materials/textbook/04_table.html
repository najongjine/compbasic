4장. 표 만들기

목표: 보고서에 업무 현황 표를 넣고, 첫 줄을 제목처럼 꾸민다.

목차이전 장다음 장

왜 표를 쓰나

담당자, 상태, 마감일처럼 비교해서 봐야 하는 내용은 문장보다 표가 훨씬 쉽습니다.

따라하기

1

표 삽입

작업
표가 들어갈 위치에 커서를 둔다.
누를 것
입력 → 표 → 4칸 x 4줄
확인
빈 표가 생기면 성공
2

표 입력

입력
업무명담당자상태마감일
고객 문의 정리홍길동완료6/10
재고표 업데이트김영희진행 중6/13
교육 안내문 배포이민수완료6/12
칸 이동
Tab 또는 마우스 클릭
3

첫 줄 꾸미기

작업
첫 줄 전체를 선택한다.
누를 것
굵게 → 가능하면 셀 배경 회색
확인
첫 줄이 표 제목처럼 보이면 성공

표에서 자주 하는 실수

실수해결
표 안에서 줄이 이상하게 바뀜칸을 클릭하고 다시 입력
칸이 너무 좁음칸 경계선을 드래그해서 넓힘
표가 지저분함첫 줄만 굵게, 배경색은 한 가지로
3장5장 보고서 완성
