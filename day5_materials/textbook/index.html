수업 시간: 3시간 / 결과물: 보고서 HWPX 3개

1장 2장 3장 4장 5장 6장
이 교재의 목표: 아래한글에서 글 입력, 글자 모양, 문단 정렬, 표 만들기, 저장을 할 수 있게 만든다.

오늘 배울 기능

1. 화면과 저장새 문서, 저장, 다른 이름 저장, 다시 열기
2. 글자 모양글자 크기, 굵게, 밑줄, 글꼴
3. 문단 모양가운데 정렬, 왼쪽 정렬, 줄 간격
4. 복사/붙여넣기문장을 옮기고 고치는 기본 작업
5. 표표 만들기, 칸 이동, 행/열 개념, 첫 줄 꾸미기
6. 제출HWPX 저장, PDF 저장, 파일명 정리
