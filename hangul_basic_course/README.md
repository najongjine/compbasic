# 중장년 컴퓨터 기초반 - 한글 기본 교재

이 폴더는 한글 프로그램을 처음 배우는 수강생이 기능 이름을 외우기보다, 실제 문서를 따라 만들면서 익숙해지도록 만든 교재입니다.

## 사용 방법

1. `01_한글_메뉴와_저장.md`부터 차례대로 엽니다.
2. 설명을 읽고, `메뉴로 찾아가기` 또는 `단축키`를 그대로 따라 합니다.
3. 각 장의 `내가 완성할 예제`를 한글에서 직접 만들어 봅니다.
4. 완성본은 `examples` 폴더의 `.hwpx` 파일을 열어 비교합니다.

## PPT 스타일 교재

- 슬라이드형 HTML 교재: `slides/index.html`
- 디자인 파일: `slides/slides.css`
- 아이콘 SVG: `slides/icons.svg`

`slides/index.html`은 브라우저에서 바로 열 수 있고, 아래로 넘기며 발표하거나 인쇄할 수 있습니다.

## 강의 흐름

| 순서 | 주제 | 완성 예제 |
|---|---|---|
| 1 | 한글과 메모장 차이, 메뉴 이해, 새 문서/저장/불러오기 | `examples/01_메뉴_저장_연습.hwpx` |
| 2 | 글자판 자동 변경 해제, 기본 타이핑 | `examples/02_글자판_입력_연습.hwpx` |
| 3 | 특수문자와 한자 변환 | `examples/03_특수문자_한자_안내문.hwpx` |
| 4 | 글꼴, 크기, 색, 밑줄, 기울임, 글자 모양, 정렬 | `examples/04_글자모양_행사안내문.hwpx` |
| 5 | 개요 번호 넣기 | `examples/05_개요번호_회의순서.hwpx` |
| 6 | 이미지 넣기와 배치 방식 | `examples/06_이미지배치_초대장.hwpx` |
| 7 | 표 만들기와 표 모양 조절 | `examples/07_표기본_연락망.hwpx` |
| 8 | 셀 합치기, 셀 배경색, 그림 넣기, 쪽 방향 | `examples/08_표응용_일정표.hwpx` |
| 9 | 찾기와 글자 바꾸기 | `examples/09_찾기바꾸기_점검문서.hwpx` |

## 수업 운영 팁

- 먼저 완성 예제를 보여주고 “오늘 이것을 같이 만든다”고 안내합니다.
- 단축키는 외우게 하기보다, 같은 작업을 3번 반복하면서 손에 익히게 합니다.
- 수강생이 막히면 기능 이름보다 “어느 메뉴에서 시작하는지”를 먼저 떠올리게 합니다.
- 마지막 10분은 자기 이름, 자기 동네, 자기 일정으로 내용을 바꾸는 시간으로 둡니다.
