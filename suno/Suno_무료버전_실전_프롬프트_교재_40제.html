SUNO PROMPT PRACTICE

프롬프트를 외우지 말고
“소리가 바뀌는 이유”를 배운다

하나의 프롬프트에서 단어 하나를 바꿔 다시 생성하고, 실제 결과가 어떻게 달라지는지 비교하면서 Suno를 익히는 실습형 교재다.

32개핵심 용어
20개Instrumental
20개보컬+가사
1원칙한 번에 하나만 변경

가장 중요한 원칙

좋은 프롬프트 = 어려운 음악용어를 많이 넣는 것이 아니다.

장르 → 분위기 → 속도 → 악기 → 보컬 → 구조 → 장면 중 필요한 것만 골라 구체적으로 만드는 것이 핵심이다.

① 처음엔 단순하게

“잔잔한 피아노곡”에서 시작해도 된다.

② 한 요소씩 추가

속도, 악기, 분위기, 구조를 차례로 붙인다.

③ 비교할 땐 하나만 변경

여러 항목을 동시에 바꾸면 무엇 때문에 결과가 달라졌는지 알 수 없다.

④ 결과를 메모

“좋다/별로다”가 아니라 무엇이 어떻게 달라졌는지 적는다.

[1] 장르 Genre + [2] 속도 Tempo / BPM + [3] 핵심 악기 Instruments + [4] 리듬 / Groove + [5] 분위기 Mood + [6] 보컬 Vocal (보컬곡일 때) + [7] 구조 Structure + [8] 장면 / 사용 목적 Scene

사람들이 실제로 찾아 듣는 음악은 어떻게 설계할까?

조회수를 보장하는 프롬프트는 없다. 대신 사람들이 음악을 찾는 이유를 먼저 잡는다.

기능 + 분위기 + 반복성

공부 / 수면 / 카페 / 독서 / 코딩 / 드라이브 / 운동 / 명상

Instrumental

“좋은 음악”보다 무엇을 하면서 듣는 음악인지가 분명해야 한다.

보컬곡

후렴에 모든 이야기를 넣기보다 한 문장 메시지와 Hook을 둔다.

유튜브형 음악 제작에 도움이 되는 5가지 습관

1청취 상황
2첫 분위기 명확히
3Hook 하나
4반복+작은 변화
5제목·이미지 통일
실제 관찰: Lofi Girl의 유명 콘텐츠는 제목부터 “beats to relax/study to”처럼 청취 목적을 직접 드러낸다. 대표 영상 보기
그대로 베끼는 것이 아니라, “누가 왜 듣는지”가 명확한 포맷을 관찰하기 위한 사례다.

무료버전으로 수업할 때

하루 50 credits

매일 충전되는 무료 크레딧으로 실습한다. 40개를 하루에 전부 생성하는 교재가 아니다.

상업적 이용 X

무료 플랜에서 만든 곡은 개인적·비상업적 이용을 전제로 한다.

다운로드 제한

무료 계정은 다운로드가 제한적이므로 최종 후보에 아껴 쓰는 편이 좋다.
