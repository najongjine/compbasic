첨부한 Word 교재를 수업용 HTML 교재로 변환해줘.

1. 기존 설명, 예제, 실습, 확인 문제와 강사용 답안을 유지해줘.
2. 차시별 메뉴를 만들어 쉽게 이동하게 해줘.
3. BPM, 박자, 리듬, 멜로디, 코드처럼 직접 구현 가능한 예제는
   재생·정지 버튼을 누르면 실제 소리가 나게 만들어줘.
4. 보컬과 실제 악기 소리처럼 음원이 필요한 예제는
   적절한 유튜브 영상을 직접 검색해서 넣어줘.
   영상 제목, 출처, 들을 구간, 집중해서 들을 특징도 적어줘.
5. 유튜브 영상은 교재 안에서 재생할 수 있도록 넣고,
   재생이 막힐 경우 사용할 원본 영상 링크도 제공해줘.
6. 음악 초보자가 이해할 수 있게 설명과 듣기 활동을 연결해줘.
7. 크롬·엣지에서 열 수 있는 완성된 HTML 파일로 제공해줘.
