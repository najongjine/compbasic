PART 1. 음악을 말로 설명하는 방법


Class 1. 음악을 어떻게 설명할까?

1. "좋은 노래 만들어줘"만으로 부족한 이유
2. 같은 장르인데도 음악이 다르게 들리는 이유
3. 음악을 구성하는 여러 가지 요소
4. 머릿속의 음악을 말로 표현하는 방법
5. 음악을 장르·분위기·속도·악기·보컬·구조로 나누어 생각하기

[실습 1] 같은 장르의 서로 다른 음악 비교하기
- 서로 다른 발라드 3곡을 들어본다.
- 세 곡이 모두 발라드인데 무엇이 다른지 적어본다.
- 빠르기 / 악기 / 보컬 / 분위기 / 강약으로 나누어 본다.

[실습 2] "좋은 음악" 구체화하기
다음 문장을 구체적으로 바꿔본다.

"좋은 노래"
→ "느리고 슬픈 분위기의 피아노 중심 노래"

"신나는 노래"
→ "빠른 템포와 강한 드럼이 들어간 밝은 댄스 음악"

[미션]
자신이 좋아하는 음악 한 곡을 선택하고
장르 / 분위기 / 속도 / 악기 / 보컬의 특징을 적어본다.


Class 2. 음악의 느낌을 구체적으로 표현하기

1. 밝은 음악과 어두운 음악

[실습 1] 반대되는 음악 듣기
- 밝은 음악 ↔ 어두운 음악
- 빠른 음악 ↔ 느린 음악
- 웅장한 음악 ↔ 소박한 음악
- 긴장감 있는 음악 ↔ 편안한 음악

각 음악을 듣고 느껴지는 단어를 3개씩 적는다.

[실습 2] 느낌 단어 카드 만들기

웅장한 / 소박한
신나는 / 차분한

3개를 골라 하나의 음악을 설명한다.

"따뜻하고 차분하면서 약간 몽환적인 음악"
