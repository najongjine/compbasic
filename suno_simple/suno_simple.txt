노래 구조{
    기본적인 노래 구조
    [Intro]          # 전주, 노래가 시작되는 부분
    [Verse]          # 절, 노래의 이야기를 전달하는 부분
    [Verse 1]        # 1절
    [Verse 2]        # 2절
    [Pre-Chorus]     # 후렴 직전 분위기를 고조시키는 부분
    [Chorus]         # 후렴, 반복되는 핵심 부분
    [Post-Chorus]    # 후렴이 끝난 후 이어지는 부분
    [Bridge]         # 노래 후반에 변화를 주는 부분
    [Outro]          # 후주, 노래를 마무리하는 부분
    [End]            # 노래의 끝

    연주 구간을 지정하는 태그
    [Instrumental]        # 가사 없이 악기만 연주
    [Instrumental Intro]  # 악기로 시작하는 전주
    [Instrumental Break]  # 노래 중간의 간주
    [Guitar Solo]         # 기타 독주
    [Piano Solo]          # 피아노 독주
    [Saxophone Solo]      # 색소폰 독주
    [Drum Solo]           # 드럼 독주

    노래의 특별한 구간
    [Hook]              # 귀에 잘 들어오는 중독성 있는 부분
    [Refrain]           # 반복되는 짧은 구절
    [Breakdown]         # 반주를 줄여 분위기를 전환하는 부분
    [Build-Up]          # 점점 긴장감을 높이는 부분
    [Drop]              # 강렬한 리듬이나 사운드가 터지는 부분
    [Interlude]         # 노래 중간의 연결 구간
    [Final Chorus]      # 마지막 후렴

    반복 및 마무리 표현
    [Chorus Repeat]     # 후렴 반복을 요청
    [Outro]             # 마무리 구간
    [Fade Out]          # 소리가 점점 작아지며 끝남
    [End]               # 노래 종료
}
