# IF 함수

## 한 줄 설명
조건이 맞으면 첫 번째 결과, 아니면 두 번째 결과를 표시합니다.

## 실제로 쓰는 상황
입금액이 청구액 이상이면 완료, 부족하면 확인으로 표시합니다.

## 기본 모양
`IF(조건, 맞을 때 값, 아닐 때 값)`

## 예시
`=IF(C2>=D2,"정상","확인")`

## 쉽게 설명하면
엑셀 함수는 어려운 영어 문장이 아니라, 반복 계산을 대신 해주는 짧은 명령입니다.
이 항목에서는 `IF 함수`을(를) 이용해 `거래처 입금 확인표`를 처리합니다.

## 수업에서 꼭 짚을 점
IF는 엑셀에서 가장 자주 쓰는 판단 함수입니다. 말로는 '만약 ~라면'입니다.

## 실습 순서
1. 청구액과 입금액을 비교합니다.
2. 입금액이 청구액 이상이면 완료로 표시합니다.
3. 아니면 확인으로 표시합니다.

## 학생에게 물어볼 확인 질문
- 이 기능을 쓰면 손으로 계산할 때보다 무엇이 편해지나요?
- 함수 괄호 안에는 어떤 값을 넣었나요?
- 결과가 이상하면 먼저 어느 범위를 확인해야 하나요?
