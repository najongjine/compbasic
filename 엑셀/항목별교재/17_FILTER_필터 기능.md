# 필터 기능

## 한 줄 설명
전체 자료 중 필요한 조건의 행만 잠시 보여줍니다.

## 실제로 쓰는 상황
입금확인이 필요한 거래처만 봅니다.

## 기본 모양
`표 안의 셀 선택 > 데이터 > 필터`

## 예시
`데이터 > 필터`

## 쉽게 설명하면
엑셀 함수는 어려운 영어 문장이 아니라, 반복 계산을 대신 해주는 짧은 명령입니다.
이 항목에서는 `필터 기능`을(를) 이용해 `거래처 상태 필터표`를 처리합니다.

## 수업에서 꼭 짚을 점
필터는 데이터를 지우는 기능이 아닙니다. 조건에 맞지 않는 행을 잠시 숨기는 기능입니다.

## 실습 순서
1. 표 안의 아무 셀 하나를 클릭합니다.
2. 데이터 탭에서 필터를 켭니다.
3. 상태 열에서 입금확인만 선택합니다.

## 학생에게 물어볼 확인 질문
- 이 기능을 쓰면 손으로 계산할 때보다 무엇이 편해지나요?
- 함수 괄호 안에는 어떤 값을 넣었나요?
- 결과가 이상하면 먼저 어느 범위를 확인해야 하나요?
