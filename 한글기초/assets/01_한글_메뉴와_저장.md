# 1강. 한글 메뉴와 저장

## 쉬운 설명

메모장은 글자를 간단히 적는 공책에 가깝고, 한글은 문서를 예쁘게 꾸미고 표, 그림, 쪽 번호까지 넣을 수 있는 문서 작성 프로그램입니다.

한글의 큰 메뉴는 작업 종류별 서랍이라고 생각하면 쉽습니다.

| 메뉴 | 뜻 | 자주 찾는 기능 |
|---|---|---|
| 파일 | 문서를 만들고 저장하는 곳 | 새 문서, 열기, 저장, 인쇄 |
| 편집 | 글자를 고치고 찾는 곳 | 복사, 붙이기, 찾기, 바꾸기 |
| 보기 | 화면을 보기 편하게 바꾸는 곳 | 확대/축소, 문단 부호 보기 |
| 입력 | 문서 안에 새 물건을 넣는 곳 | 표, 그림, 특수문자 |
| 서식 | 글자와 문단 모양을 꾸미는 곳 | 글자 모양, 문단 모양, 개요 |
| 도구 | 한글 사용 환경을 고치는 곳 | 글자판, 환경 설정 |

## 메뉴로 찾아가기

- 새 문서: `파일 > 새 문서`
- 저장: `파일 > 저장`
- 다른 이름으로 저장: `파일 > 다른 이름으로 저장`
- 불러오기: `파일 > 불러오기`

## 단축키

- 새 문서: `Ctrl + N`
- 저장: `Ctrl + S`
- 불러오기: `Ctrl + O`
- 인쇄: `Ctrl + P`

## 이 기능으로 할 수 있는 것

- 안내문을 만든 뒤 내 이름으로 저장할 수 있습니다.
- 어제 만든 문서를 다시 열어 이어서 고칠 수 있습니다.
- 문서 이름만 보고 어떤 내용인지 알 수 있게 정리할 수 있습니다.

## 내가 완성할 예제

완성본: `examples/01_메뉴_저장_연습.hwpx`

1. 새 문서를 엽니다.
2. 제목에 `나의 첫 한글 문서`라고 입력합니다.
3. 이름, 날짜, 오늘 배운 메뉴를 입력합니다.
4. 파일 이름을 `01_내이름_첫문서.hwpx`로 저장합니다.
5. 한글을 닫았다가 다시 열어 저장한 문서를 불러옵니다.

확인할 것: 문서가 사라지지 않고 다시 열리면 성공입니다.
