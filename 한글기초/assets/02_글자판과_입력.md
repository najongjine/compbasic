# 2강. 글자판 자동 변경 해제와 기본 입력

## 쉬운 설명

글자판은 키보드 입력 방식을 말합니다. 한글을 쓰다가 갑자기 영어가 나오거나, 원하지 않는 글자판으로 바뀌면 글자판 자동 변경을 꺼두면 편합니다.

## 메뉴로 찾아가기

- 글자판 자동 변경 해제: `도구 > 글자판 > 글자판 자동 변경`
- 체크가 켜져 있으면 한 번 눌러 체크를 끕니다.

## 단축키와 기본 입력

- 한/영 전환: 키보드의 `한/영`
- 줄 바꾸기: `Enter`
- 한 칸 띄우기: `Space`
- 지우기: `Backspace`
- 커서 앞 글자 지우기: `Delete`

## 이 기능으로 할 수 있는 것

- 한글과 영어가 섞인 문장을 안정적으로 입력할 수 있습니다.
- 이름, 주소, 전화번호처럼 실생활 문서를 직접 입력할 수 있습니다.
- 오타를 고치면서 문장을 천천히 완성할 수 있습니다.

## 내가 완성할 예제

완성본: `examples/02_글자판_입력_연습.hwpx`

1. 제목 `기본 입력 연습`을 입력합니다.
2. 자기 이름, 사는 동네, 좋아하는 음식 3가지를 입력합니다.
3. `Hancom Office`처럼 영어가 들어간 문장을 입력합니다.
4. 글자판 자동 변경이 켜져 있으면 꺼보고 다시 입력합니다.

확인할 것: 한글과 영어가 내가 원하는 대로 입력되면 성공입니다.
