# 4강. 글자 모양과 정렬

## 쉬운 설명

글자 모양은 글자의 옷을 바꾸는 기능입니다. 제목은 크게, 중요한 글자는 진하게, 날짜와 장소는 보기 좋게 정렬하면 문서가 훨씬 읽기 쉬워집니다.

## 메뉴로 찾아가기

- 글자 모양: `서식 > 글자 모양`
- 문단 정렬: `서식 > 문단 모양` 또는 도구 상자의 정렬 버튼
- 글꼴/크기/색: 화면 위쪽 서식 도구 상자

## 단축키

- 글자 모양 창: `Alt + L`
- 굵게: `Ctrl + B`
- 밑줄: `Ctrl + U`
- 기울임: `Ctrl + I`
- 가운데 정렬: `Ctrl + Shift + C`
- 왼쪽 정렬: `Ctrl + Shift + L`
- 오른쪽 정렬: `Ctrl + Shift + R`

## 이 기능으로 할 수 있는 것

- 행사 안내문 제목을 크게 만들 수 있습니다.
- 중요한 문장에 밑줄을 넣어 눈에 띄게 할 수 있습니다.
- 문서 제목은 가운데, 본문은 왼쪽으로 정리할 수 있습니다.

## 내가 완성할 예제

완성본: `examples/04_글자모양_행사안내문.hwpx`

1. 제목 `건강 걷기 모임 안내`를 입력하고 크게, 굵게, 가운데 정렬합니다.
2. 날짜와 장소는 본문보다 조금 크게 만듭니다.
3. 준비물 문장에 밑줄을 넣습니다.
4. 문의 전화번호는 파란색으로 바꿉니다.

확인할 것: 제목, 본문, 강조 문장이 서로 다르게 보이면 성공입니다.
