기본

쉬운 설명

한글은 문서를 꾸미는 작업실입니다

메모장은 간단한 글쓰기, 한글은 표·그림·쪽 번호까지 넣는 문서 작성 프로그램입니다. 큰 메뉴는 작업 종류별 서랍이라고 생각합니다.

6강. 이미지 넣기와 배치
그림

그림은 넣는 것보다 배치가 중요합니다

글자처럼 취급

그림이 큰 글자처럼 움직입니다. 처음 배울 때 가장 안정적입니다.

어울림

글자가 그림 주변을 감쌉니다. 안내문과 초대장에 좋습니다.

글 뒤로

그림이 배경처럼 뒤에 깔립니다. 희미한 배경에 씁니다.

실습: 우리 동네 작은 음악회 문서에 같은 그림을 넣고 세 가지 배치를 모두 바꿔 봅니다.

9강. 찾기와 글자 바꾸기
수정

긴 문서에서는 눈으로 찾지 않습니다

찾기는 원하는 단어 위치를 보여주고, 바꾸기는 같은 단어를 한꺼번에 고쳐 줍니다.

Ctrl + F 찾기

Ctrl + H 바꾸기

바꾸기 실습

  1. 홍길동을 자기 이름으로 바꾸기
  2. 6월 20일을 실제 수업 날짜로 바꾸기
  3. 마을회관을 원하는 장소로 바꾸기

같은 단어가 빠짐없이 바뀌면 성공입니다.

예제: 09_찾기바꾸기_점검문서.hwpx9 / 9
